# MD Atik - Personal Portfolio (Header & Hero)

A responsive landing page focusing on a modern **header + hero section UI**, built using only **HTML5 and CSS3**. The design emphasizes simplicity, responsiveness, and a soft green modern aesthetic.

## Features

- Fully responsive layout (desktop, tablet, mobile)
- Modern glassmorphism navigation bar
- Clean hero section with fluid typography
- CSS variables for easy theme customization
- Semantic and accessible HTML structure

---

## Tech Stack

- HTML5
- CSS3 (Flexbox + Media Queries + Variables)

---

## Project Structure


- index.html # Contains Header + Hero section markup
- style.css # Styling, variables, and responsive rules


---

## Getting Started

To run this project locally:

1. Clone or download this repository
2. Keep `index.html` and `style.css` in the same folder
3. Open `index.html` in any modern browser
